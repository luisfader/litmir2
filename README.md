# Литературный мир — Роберт Фадер

Русский сайт с романами Роберта Фадера: https://luisfader.github.io/litmir2/

Всё читается свободно, без регистрации. Романы на других языках — на сайте https://luisfader.github.io/litmir/ (репозиторий `luisfader/litmir`); ссылки на переводы ведут туда.

## Структура

```
index.html                  весь сайт (сборка не нужна)
novels/catalog.json         список романов, названия, описания и главы
novels/<роман>/             по одному файлу .md на главу (01.md, 02.md, …)
blog/ru/                    записи блога, список в blog/catalog.json
learn/ru/                   курс русского языка, список в learn/catalog.json
characters.html             персонажи (characters/catalog.json)
```

## Добавить роман

1. Создать папку `novels/<короткое-имя>/` с файлом на каждую главу.
2. Добавить роман в `novels/catalog.json` (`"lang": "ru"`) со списком глав.
3. По желанию — обложка: `"cover": "novels/<короткое-имя>/cover.jpg"`.

Формат текста: абзацы через пустую строку, `*курсив*`, `**жирный**`, `***` — смена сцены.

Комментарии (Giscus) хранятся в Discussions репозитория `luisfader/litmir`, поэтому старые обсуждения сохранились.
